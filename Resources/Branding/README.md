# ByteEngine identity

User-selected concept B: Open Frame. Original vector artwork is in ByteEngine.svg; PNG/ICO are derived renders. ByteEngine-splash.gif is a 40-frame, 80 ms/frame looping animation of the same mark and wordmark. These are original project graphics; no external logo/font license is bundled into the icon.

Editor and Windows player ApplicationIcon use the ICO. The native launcher resource embeds it. The Windows player embeds the GIF and closes its separate startup window on the first rendered frame. The browser ships PNG/GIF assets with its loading screen.
