ByteEngine native networking uses DataChannelDotnet1.3.1 (NuGet package, MIT),
with libdatachannel and its native dependencies. The browser uses built-in WebRTC.

Package: https://www.nuget.org/packages/DataChannelDotnet/1.3.1
Package source reference: https://github.com/ZetrocDev/DataChannelDotnet
libdatachannel source: https://github.com/paullouisageneau/libdatachannel
Unmodified native library is dynamically linked; MPL source is available upstream.
OpenSSL source: https://github.com/openssl/openssl
libjuice source: https://github.com/paullouisageneau/libjuice
usrsctp source: https://github.com/sctplab/usrsctp

License texts are shipped alongside this notice. No native library sources were modified.
