FPS MANNEQUIN ARMS

Arms-only derivative of your full mannequin, with a narrow central gap matching the arms concept. Shoulder line is at local Z=0; +X is character left. Front is -Y.

DEFAULT: straight T-pose, palms down.
Select FPS_Arms_RIG and enter Pose Mode. Rotate clavicle, upper_arm, forearm, hand and finger bones for FK.
Optional IK: select CTRL_hand_IK.L or .R, change custom property Arm IK to 1, move the wrist target and elbow pole. Set Arm IK to 0 to use FK. No stretch.
FPS_Ready_Pose is a stored one-frame action; assign it to preview the first-person stance. The FPS camera is positioned where the head would be.

60 skinned mesh pieces, editable subdivision, normalized explicit weights; fingers have rounded knuckle inserts. Reference concepts are packed in the hidden REFERENCE collection. Studio and control shapes are hidden in the viewport.
