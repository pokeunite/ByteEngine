These three bundled fonts are from GGBotNet's [fonts-cc0](https://github.com/ggbotnet/fonts-cc0) repository, revision `670059749032c2310422b2287c24307b23656080`:

| Font | Style | SHA-256 |
| --- | --- | --- |

| OSerif-Regular.ttf | serif | `3F9B588DFFD3263D8E610DB17302FBCC4D52C452BED994501F31E6B623AB7E40` |
| PublicPixel.ttf | pixel | `931EB4BF9EF25A6D4BB31783B8681712A42B7408988D53971A3070A2F7443CCF` |

The upstream project identifies these fonts as **CC0-1.0**. Its full license is included as `CC0-LICENSE.txt`. ByteEngine copies that notice into projects when installing the fonts.

Custom fonts are imported into each project's Assets folder, not into the engine installation. This keeps project references portable and lets creators choose fonts under licenses appropriate to their games.
