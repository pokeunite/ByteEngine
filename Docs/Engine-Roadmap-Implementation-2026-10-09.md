# Engine roadmap implementation and validation — 9 October 2026

All twelve roadmap workstreams now have engine implementations and local acceptance checks. This is not a claim of Godot feature parity. The [roadmap audit](Godot-Comparison-Improvement-Roadmap.md) records scope and limitations.

## Using the new systems

- In a scene's Inspector, enable **Fixed Simulation** deliberately. Fixed hooks drive general physics and migrated built-in simulation; normal update still drives input/presentation. The clock bounds catch-up and reports dropped time. Physics transforms render between the previous/current fixed pose; collision queries remain authoritative. Reset interpolation when teleporting.
- General rigid bodies opt into rotation and continuous collision. MeshCollider3D supplies static triangle surfaces and validated convex hulls independently of render LODs. Its status reports malformed/open/concave hulls; dynamic hulls are capped at 128 vertices/256 triangles. Box CCD uses a conservative enclosing sphere and can stop early for elongated geometry. Capsule CCD uses actual endpoints/radius. This is not relative-motion or rotational CCD. Sleeping requires a quiet supported contact island. Distance/Hinge joints connect separate general-physics bodies by object GUID; hinge motors/limits are reusable engine components.
- Spatial queries refresh live bounds for editor moves/teleports. The BVHs reduce candidates, but gathering bounds is still O(n). Motion refits the existing moving tree, with periodic rebalancing; membership changes rebuild it. Compound colliders retain distinct enter/stay/exit identities.
- Property gestures capture selected objects; retained undo records contain changed objects instead of entire scenes. Exact unchanged component matches are reserved before restoring changed/removed same-type components. Complex scene/global operations retain snapshot fallback. Components with private opaque serialized state may be reconstructed when changed.
- Changed model imports run on a serialized CPU worker, with only the latest result published on the owning thread. Content/settings/dependency fingerprints identify binary cached results. GL resource publication remains on the owning thread. Asset Browser expansion queues first-use import without blocking; explicit LoadModel remains synchronous for callers needing an immediate result and reuses the same cache. Derived model data has a 512 MiB LRU budget; texture data is hydrated before cache eviction. Model and cooked texture writes are atomic.
- Native profiling separates viewport/pass CPU scopes and delayed GPU timestamps. GPU samples are asynchronous and include sample age; unavailable values are not zero. Browser geometry uses `EXT_disjoint_timer_query_webgl2` when supported; Canvas UI timing is CPU. Captures are available from the Performance panel.
- Opaque matching mesh/material/shadow-receive submissions instance on native OpenGL and WebGL2. Transparent objects retain individual sorting. Import settings offer generated static LOD submeshes; automatic projected-size selection uses per-viewport hysteresis. Runtime generated groups preserve their source mesh and remove generated resources on stop. Collision geometry is unchanged. Vertex clustering is unsuitable for skinned or silhouette-critical assets.
- Navigation regions bake inflated static obstacle footprints. Optional heightfield sampling adds slopes/steps and waypoint elevation. Agents follow bounded paths; dynamic rigid bodies are not moved behind their solver. Traversal links bridge otherwise disconnected cells. Show Debug draws region/path overlays. Choose Grid or MeshSurface baking. MeshSurface uses an authored MeshCollider3D surface, triangle adjacency, slope filtering, clearance portals and links; separate height layers remain disconnected unless linked. Obstacle rejection is conservative rather than Recast-style polygon cutting; tessellate authored navigation surfaces appropriately.
- Blueprint variants inherit through a base asset and saved baseline. Three-way merge keeps local changes and reports conflicts. The Inspector lists transform/component property overrides and can apply or revert one; same-type component ordinals distinguish compound components. Nested identities, joint targets and object maps are remapped during placement; source propagation preserves parents and intentional overrides. Nested variants expose inheritance conflicts in the Inspector.
- UI containers compute layout without rewriting authored offsets. Scroll containers clip rendering and pointer hit tests and reveal focused rows. Widgets support content sizing and min/max constraints; text/button fitting uses measured font metrics. Assets > Create > UI Theme makes a `.uitheme` palette assignable to a Theme component. Window > UI Authoring provides actual rendered resolution previews, outlines and selection through gameplay hit-testing rules. Long German/French labels and gamepad navigation/confirmation are covered. Complex script shaping/accessibility remain separate extensions.
- Native music streams PCM WAV or Ogg Vorbis through three bounded OpenAL buffers. Browser music uses media elements and first-use short-clip decoding, with a 32 MiB decoded cache target and inactive URL eviction. Encoded package files still occupy browser memory. Buses, ducking and voice priorities apply to both backends. Reset stops tracked voices before clearing the budget.

## Scope limits and later extensions

General physics is a bounded iterative solver, not a replacement for the specialized vehicle backend. See [ownership rules](PHYSICS-BACKEND-BOUNDARY.md). Conservative box CCD may stop early; fast relative motion and rotational CCD need separate work. Queries still gather live collider bounds in O(n) to see editor edits/teleports immediately. Complex undo operations retain snapshot fallback. Explicit synchronous model loads remain available. Navigation mesh baking conservatively rejects blocked triangles and requires authored tessellation; dynamic obstacle avoidance is not implemented. Generated LOD applies to static meshes; transparent draws and skinned LOD retain their existing paths, and shadow-pass batching is not claimed. Browser rendering has documented reduced effects. Full script shaping/accessibility, hosted itch performance and remote CI execution remain unverified extensions.
