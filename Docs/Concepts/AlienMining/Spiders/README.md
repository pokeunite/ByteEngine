# Eight-legged spider references

Final references generated with the built-in image generation tool:

- `PlayerHunter-eight-legs.png`: lean charcoal/violet runner, red-orange markings, long agile legs; attacks the operator.
- `DrillBreaker-eight-legs.png`: broad mineral-armoured spider, ochre plates, thick legs and crushing mouthparts; attacks the drill.

Both final images have eight walking legs: four separate feet and knees per side. The earlier three-quarter variants were rejected because the views did not provide a reliable eight-leg layout. The higher, near-top-down rest views separate all four leg pairs for modelling and bone placement.

These are images, not rigged 3D assets. Model the legs as eight distinct connected limbs with clear joints and sufficient spacing, attach them to the cephalothorax, retain a separate abdomen silhouette and keep mouthparts distinct from walking legs. Maintain this neutral stance when preparing the unrigged model for Mesh2Motion; test weight assignment and collisions after fitting the spider template.

Mesh2Motion's official [release notes](https://mesh2motion.org/news) describe a spider skeleton and nine animations, including idle, walk, attack and death. Its [creation tool](https://app.mesh2motion.org/create) takes a 3D model, then provides orientation, floor alignment, skeleton fitting and animation selection. A concept image itself is not a model that can be uploaded for rigging.

`prompts.json` preserves the initial design prompts and the anatomy/camera correction prompts. Palette and silhouettes match the current alien canyon rather than the industrial-yellow camp machines.
