# Alien mining concept set

Generated using the built-in image-generation tool, informed by the supplied Zombillionaire recording. These are original modeling references and interface concepts, not imported 3D meshes or implemented screens.

Shared direction: chunky frontier industrial equipment for a top-down alien mining business game; mustard-yellow paint, charcoal steel, cream service panels and restrained cyan screens. Clear silhouettes and separate moving parts. Neutral studio sheets with main three-quarter and supporting views.

Prompt subjects:

- **Drill:** open gantry, central spiral auger, four stabilizer feet, top motor, ore hopper and side controls. Tall silhouette readable from above.
- **Refinery:** broad low processing drum on a skid, ore hopper, two short stacks, orange furnace window and ingot output tray. Distinct from drill.
- **Ammo press:** compact C-frame, flywheel, press ram, short conveyor, safety shield and collection tray. Separate moving components; no manufacturing blueprint.
- **Company tent:** open-front expedition canvas shelter, folding computer desk, market screens, communications antenna, supply crates and a restrained cyan work light. Roof cutaway to show usable interior from the game camera.
- **UI:** top-down combat with minimal persistent counters; small machine upgrade panel with stat/current/next/cost rows; separate market screen with current price, history, stock, quantity and sell total. Consistent restrained dark surfaces and readable type. Concept values are illustrative.
