Implemented animation changes

  • Repeated vertices sharing a bone/weight combination reuse a blended palette matrix rather than recalculating four full weighted transforms per vertex. Palette buffers are reused.
  • Bone-name lookup is cached per skeleton, preserving exact-name preference and case-insensitive fallback.
  • Unchanged socket model transforms reuse cached results. New poses, authored socket edits and root correction changes invalidate the result; world movement remains live.
  • Follower updates use a single-follower fast path or pooled snapshots instead of allocating a fresh array after every pose.
  • Large native meshes have a tested worker skinning option, with disjoint vertex ranges and deterministic bounds reduction. It is disabled by default because it was slower on this laptop. Browser skinning remains serial and benefits from palette sharing.

Verification

Skinning matches the original four-influence reference within 0.00001 for a 96,000-vertex test including invalid influences and unweighted vertices. Serial and worker outputs match exactly. Ten thousand warm socket queries allocate 40 bytes total (the benchmark timer), with tests for pose edits, socket edits, missing bones and parent/world movement. Existing animation/socket module regressions, native spider animation checks and 178 gameplay checks pass.
