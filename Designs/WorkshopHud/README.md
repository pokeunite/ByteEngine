# Goblin workshop 0.3.4

Brace: Structure category, last page. Click two connectors. Escape cancels. Use Erase to delete the span, or X while pointing at it. Undo/redo and saved machines retain both endpoints. The master block remains protected.

The brace is rigid reinforcement, with no collider along its middle. It follows Root or Moving endpoints. Do not brace across an actuator you expect to move. This pass does not reproduce stress-based breakage or special zero-length brace cubes.

HUD: compact top toolbar and bottom categories/part tray; actual part renders, contextual tooltips, placement feedback and mass/count. Uses Lucide ISC icons, existing Kenney CC0 prompts and Barlow OFL fonts. All licenses are retained. No AI-generated UI images.

The reference review and images are in WORKSHOP-REVIEW.html. Local extracted game source was inspected but is not shipped in the plugin.

Save and restart the editor to load the installed package. Source: Plugins/GoblinScrapper. Saved package: PluginLibrary/GoblinScrapper.byteplugin and Downloads/ByteEngine Plugins/GoblinScrapper.byteplugin.
