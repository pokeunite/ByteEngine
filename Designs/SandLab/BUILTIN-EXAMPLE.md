# Interactive Sand — built-in ByteEngine example

Open InteractiveSand.byteproject and press Play. Click the game view to focus input.

WASD: move the ball. Tab: switch between ball grooves and twin tyre tracks.
F6: clear tracks. I/J/K/L: orbit camera. U/O: zoom.

The editable scene contains the sand, blue ball, camera, sunlight, sky and controls.
Select Interactive sand to tune contact depth, shoulder height, ripple height and sand colour.
Select Blue ball to tune movement speed and tyre mode.

No plugins or external assets are required. New Project > Interactive Sand recreates this example.
The 32m surface uses persistent GPU displacement and matching CPU height sampling.
This is a contact-field demo, not a particle/granular sand simulation. Tracks reset when Play restarts.
